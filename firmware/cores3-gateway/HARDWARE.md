# Hardware to buy

Purchase before flashing this package. Do not buy a random CoreS3 plus a mismatched H2.

## Required for MVP 1

1. [M5Stack CoreS3 Thread BR (K149)](https://docs.m5stack.com/en/app/thread_br)
   - CoreS3 + Module Gateway H2 + DIN base
   - UART on this kit: H2 RX = GPIO10, TX = GPIO17
2. One IKEA **Matter-over-Thread** bulb (KAJPLATS, Matter logo on the box)
   - Do not buy old TRADFRI Zigbee-only bulbs
   - No DIRIGERA hub

## Next devices

## Home network

The CoreS3 Wi-Fi LAN needs working IPv6. Thread commissioning often fails as an IPv6 routing problem.
