# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository. Please do not open a public issue for a security problem.

Include what you found, how to reproduce it, and the impact. You should hear back within a week.

Do not commit Wi-Fi passwords, Matter setup codes, Thread network datasets, device certificates, or cloud credentials. Those belong in a local `.env.local` or in SSM, never in git.
